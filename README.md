# Proyecto 3 – Katas Python 

## Descripción
Este proyecto corresponde al **Proyecto 3 – Katas Python**, cuyo objetivo es afianzar y demostrar los conocimientos adquiridos en Python mediante la resolución de una serie de ejercicios prácticos (katas).

A lo largo del proyecto se trabajan distintos conceptos fundamentales del lenguaje, aplicando buenas prácticas, código claro y comentarios explicativos que reflejan el proceso de aprendizaje.

Una vez finalizado, el proyecto se entrega mediante un repositorio de GitHub cuyo enlace se envía por correo electrónico.

---

## Objetivos del proyecto
El desarrollo de estas katas permite demostrar conocimientos en:

- Manejo de tipos de datos básicos y funciones incorporadas.
- Uso de estructuras de datos en Python (listas, diccionarios, sets, tuplas) y sus métodos.
- Uso de condicionales (`if`, `elif`, `else`).
- Uso de estructuras de iteración (`for`, `while`).
- Creación y uso de funciones.
- Introducción a la Programación Orientada a Objetos (clases).
- Uso de módulos estándar de Python.
- Aplicación de buenas prácticas de programación.
- Escritura de código legible y bien comentado.

---

## Estructura del proyecto

El repositorio contiene, al menos, los siguientes elementos:

- 📄 **Archivo `.py`** con todos los ejercicios resueltos.
  - Cada ejercicio está encabezado por un comentario con su enunciado.
  - El código incluye comentarios explicativos, especialmente en las partes más complejas.
- 📝 **Comentarios** que recogen el razonamiento y los pasos seguidos durante el desarrollo.
- 📘 **README.md** con la explicación general del proyecto (este archivo).

## Buenas prácticas aplicadas

- Uso de nombres de variables descriptivos.

- Funciones pequeñas y con una única responsabilidad.

- Comentarios claros para explicar la lógica del código.

- Evitar duplicación de código.

- Manejo de errores y excepciones cuando es necesario.

## Uso de herramientas de IA 🤖

El uso de herramientas de Inteligencia Artificial está permitido en este proyecto.
No obstante, se han utilizado de forma responsable, asegurando en todo momento la comprensión del código y del razonamiento detrás de cada ejercicio.

Este proyecto está enfocado en consolidar el aprendizaje, no solo en obtener el resultado final.
